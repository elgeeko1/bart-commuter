# Product guidelines

These apply to anything a rider sees in a widget.

## Clear order of importance

The next departure dominates. Each level of detail below it is smaller and quieter, so a rider finds the next train in under a second.

## One consistent pattern

The same kind of information looks the same in every widget size and every service state, so learning one widget teaches the others.

## Problems show up in the field they relate to

A state that affects a value appears where that value would be, for that trip alone. Banners and distant notes make the rider connect the problem to the value.

## Text is readable

Text and symbols keep enough contrast and size to read at a glance, on every background and in light and dark.
